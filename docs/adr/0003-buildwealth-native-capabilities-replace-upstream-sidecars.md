# BuildWealth-native capabilities replace upstream sidecars

BuildWealth will not keep Ghostfolio or Ignidash as long-term runtime, UX, API, module, or product-language concepts. Their useful behaviors will be rebuilt as BuildWealth-native capabilities owned by the orchestrator and v2 UI, using canonical names such as Portfolio Analytics Engine, Import Workbench, Asset Registry, Plan Simulation Engine, and Plan Strategy Lab; external app names are limited to historical provenance or migration notes while those references are being removed.
