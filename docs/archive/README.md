# Archive

These are the working documents from building BuildWealth: dated implementation
plans, roadmaps, product explorations, and UX strategy notes. They are kept for
transparency, not as current documentation. Many are superseded, and some
describe ideas I decided not to build.

For current documentation, start with the [README](../../README.md),
[ARCHITECTURE.md](../ARCHITECTURE.md), the [ADRs](../adr/), and the domain
glossary in [CONTEXT.md](../../CONTEXT.md).

`agent-plans/` holds step-by-step implementation plans written for AI coding
agents. Most features started as one of these: I wrote and reviewed the plan,
an agent implemented it, and I reviewed the result against tests. They show
how I break down work for agent execution.
